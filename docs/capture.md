# Public capture and paper execution

Generate the offline fixture and save a run using the [clean checkout walkthrough](../README.md#open-the-app). The synthetic capture is dated November 15, 2026 at 17:10:30Z. Four mock polls cover the station weather and six Polymarket US books; one book reprices sharply. The fixture verifies fill, skip and accounting behavior without a trained local model.

For a bounded **public** command-line capture after the locked install:

```sh
uv run --locked python -m weather_edge.capture --duration-seconds 60 --poll-seconds 8 --with-grids
```

The command makes public GET requests and writes one timestamped JSON file atomically in `.data/captures/`. Open the normal app after capture to load it. The default is up to 12 daily-high events, eight book polls, and a 45-second request window. Increase the time within the 180-second limit to collect more independent observations. HTTP errors and missing ladders remain gaps. The capture records request, receipt and exchange timestamps and keeps the depth window returned by the exchange. It fetches NOAA station guidance, exact-station NWS observations, and a single combined AWC METAR response per weather refresh. Station feeds are first usable at their actual receipt time. The optional `--with-grids` phase caches temperature fields for this session's globe within the same time budget. Use `--with-clouds` to acquire both temperature and matching cloud fields.

A subsequent capture queries final payouts for eligible events that it previously captured. The ledger keeps collateral committed until a final payout is available from the exchange, using the receipt as the first verified time when the payout could enter the ledger. Each session can poll up to 36 past buckets. Payouts not yet available can arrive in a later session.

## Exchange interpretation

- Discovery uses the public [weather tag event endpoint](https://docs.polymarket.us/api-reference/tags/get-events-for-a-tag). Embedded market IDs and `marketSides.long` establish the instrument and YES/NO mapping. The supported settlement stations are KNYC, KPHL, KMIA, KMDW, KSFO and KLAX. The instrument rules establish the station and temperature comparison. The NWS test window is midnight to midnight local standard time. Between means both bounds are inclusive. When a boundary is explicitly shared, the higher bracket receives it. [QCX Temperature Contracts filing](https://www.cftc.gov/IndustryOversight/IndustryFilings/TradingOrganizationProducts/60333), [NWS observations FAQ](https://www.weather.gov/lot/weather_observations_faq).
- The public [market book endpoint](https://docs.polymarket.us/api-reference/markets/get-market-book) returns one long-side ladder. Buying YES walks the offers. A short position is economically equivalent to buying NO at one minus the YES bid and uses the bid's displayed size. The watcher preserves only the returned window. The official [Markets WebSocket](https://docs.polymarket.us/api-reference/websocket/overview) requires an API key, so the bounded collector uses public REST. [Polymarket US market structure](https://docs.polymarket.us/learn/trading/basics/buying-yes-vs-selling-no).
- [Weather Edge's Polymarket US paper policy](../weather_edge/poly_fee_policy.py) uses 0.0695 before November 14, 2026 at 05:00Z and 0.095 from that instant. It models a standard Tier 1 taker, with cumulative half-even cent rounding and no rebates or onboarding relief. These are paper assumptions. The [dated fee evidence](audit-listing-fee-verification.md#fee-policy-evidence) records venue notices and the intervening document gap.
- The exact listing must support the reviewed coefficient. A conflicting advertised fee blocks paper pricing even if a price is visible. The simulation locks the coefficient at the signal; the delayed receipt supplies a new ladder and may change price, size or edge. New freezes carry the schedule and older runs retain theirs.
- Exchange market-end metadata is shown as the contract-specific scheduled time. The [Weather FAQ](https://docs.polymarket.us/faqs/weather-faqs) gives a general 8 a.m. ET schedule, a possible delay for review and a fair-price fallback if no report appears within a week. The public [settlement endpoint](https://docs.polymarket.us/api-reference/markets/get-market-settlement) supplies the actual payout value when published, without an actual payout timestamp.

## Paper bankroll

Every supported bucket can produce YES and NO rows, including 99¢ favorites. The break-even probability is all-in cost divided by filled contracts. Estimated net EV is model side probability times contracts less that all-in cost, which is also maximum loss. The scan checks price levels and partial levels for the best dollar EV within the order budget. With no positive prefix, it displays the economics of the deepest eligible fill. The scanner shows current book economics when a probability is unavailable and marks probabilities with weak validation support.

## Paper orders and recheck clocks

- **Live Trade** uses a [30-second reaction delay and a separate 15-second recheck window](../weather_edge/trade.py). The exact contract cutoff can shorten that window. The synthetic Trade fixture uses five seconds. The Weather trial and Backtest browser forms default to 30 seconds (five in the fixture) and accept a configurable delay; the `paper_runs save` CLI defaults to five seconds and accepts `--reaction-seconds`. These settings do not change the live order delay.
- Live checks require [strict evidence](../weather_edge/paper_eligibility.py): the book must be received on or after the reaction target and first available to the app by the deadline while the listing and exact side still qualify. It needs usable depth, an open venue state, and an exchange image at or before the decision and no more than two minutes old. A regressing image clock or conflicting ladder at the same clock fails. A new origin-confirmed receipt can carry an unchanged, still-fresh image; a matching cache hit can support the origin preview through an earlier qualifying receipt and cannot supply the delayed origin receipt.
- `--freshness origin-confirmed` requires affirmative origin evidence and no Age header; `legacy` applies the older receipt/cache checks without requiring affirmative origin headers. Live CLI saves default to origin-confirmed freshness with app availability. Fixture saves default to legacy freshness and the fixture's HTTP receipt clock. `--clock-basis http-receipt` is a separate explicit CLI choice; it does not turn display prices into depth. Do not read a legacy result as proof under today's strict rules. See [replay and frozen engines](replay.md#open-and-reproduce-a-saved-result).
- The default bankroll is $500 with $25 maximum gross cost per station and climate day. The first eligible delayed receipt still has to support positive edge and fit the limits. Trade preserves the reviewed quantity and price cap. Payouts release commitments only at their own verified availability clock.
